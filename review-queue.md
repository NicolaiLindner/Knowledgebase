# Review-Queue (append-only)

Prüfaufträge statt Kaskaden-Updates: Wenn ein Edit Nachbarseiten berühren KÖNNTE, hier eintragen statt still mitzuschreiben. Erledigtes abhaken (`[ ]` → `[x]`, Beleg hinter ` -- `), nie löschen.

Format: `- [ ] YYYY-MM-DD | TYP | seiten-name[, seiten-name] | Grund [wartet: Nutzer|Kollegen|Deploy]`
TYP: `PRUEFEN` (Agent kann selbst prüfen) · `ENTSCHEIDUNG` (braucht Nutzer/Kollegen) · `NACHZUG` (Folgeänderung nach Entscheidung) · `DOKU` (nur dokumentieren)
